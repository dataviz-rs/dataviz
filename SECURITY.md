# Security policy

## Supported versions

Security fixes go into the latest release of each package: the `dataviz`
crate (1.x), `dataviz-mcp`, the C library, `dataviz-rs` on PyPI and
`dataviz-rs` on npm.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/dataviz-rs/dataviz/security/advisories/new).
Include the affected package and version, and a way to reproduce it.

You should get a reply within a week. Once a fix is released, the advisory
is published with credit to the reporter, unless you prefer otherwise.
