# Assets

- `DejaVuSans.ttf`: the embedded default font (license in
  `DejaVuSans-LICENSE.txt`).
- `world_110m.bin`: country outlines of Natural Earth's 1:110m Admin 0
  countries (public domain, <https://www.naturalearthdata.com>), converted
  with `tools/gen_world.py`.
- `admin1.bin`: states and provinces of Natural Earth's 1:10m Admin 1
  (public domain), simplified and compressed with `tools/gen_admin1.py`
  (feature `regions`).
